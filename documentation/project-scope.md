# Project Scope

## Implemented in DriveX 1.0
- Arduino Nano control
- Bluetooth manual driving
- Two-mode operation
- L298N motor control
- Ultrasonic obstacle detection
- Servo-based sensor scanning
- I2C LCD feedback

## Future scope
- Camera and computer vision
- Object/person detection
- GPS/Wi-Fi remote monitoring
- Voice control
- Cloud data logging

The future-scope concepts are **not claimed as implemented features of DriveX 1.0**.
