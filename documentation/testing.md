# Testing & Results

The submitted project report records these project-test observations:

- Bluetooth mode: manual directional control from a smartphone.
- Obstacle mode: automatic obstacle detection and avoidance.
- LCD: active mode, movement and distance information.
- Mode switching: performed without rebooting.
- Reported Bluetooth range: approximately 10–12 m.
- Reported battery runtime: approximately 45 minutes continuous operation.

These are project observations, not laboratory-certified specifications. Actual performance depends on battery condition, environment, motor load and Bluetooth conditions.
